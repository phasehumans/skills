### Install

```bash
december skill add phasehumans/skills
```

Or install globally:

```bash
december skill add phasehumans/skills --global
```

Every skill is immediately available in your December terminal session as a slash command.

### Skills

- **grill-me**: Clarifies requirements and edge cases before writing code
- **plan**: Creates a step-by-step implementation plan with verification steps
- **to-spec**: Turns ideas into a clear technical specification
- **to-tickets**: Breaks a specification into small, actionable tasks
- **implement**: Builds and tests features step-by-step
- **code-review**: Reviews code changes for bugs and quality
- **tdd**: Follows a test-driven development cycle
- **debug**: Finds and fixes the root cause of bugs systematically
- **refactor**: Simplifies code and reduces complexity without breaking tests
- **security-review**: Audits code for vulnerabilities and leaked secrets
- **pr-ready**: Verifies checks and drafts a clean pull request summary
- **explain**: Explains architecture and complex code in plain English
- **handoff**: Saves session context for another agent
- **setup-december-skills**: Configures project docs and setup
